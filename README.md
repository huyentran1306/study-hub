## 🎨 Trải Nghiệm & Hiệu Ứng Giao Diện

* **Mascot Speech Balloon**: Khối linh vật tương tác tự động gõ chữ (Typewriter effect) luân phiên các câu nói truyền cảm hứng học tập.
* **Dynamic Particle FX**:
  * *Study-En*: Ký tự code & cú pháp lập trình `{ }`, `</>`, `λ`, `⚡` bay bổng với tông màu Electric Indigo.
  * *Đi Đâu AI*: Biểu tượng du lịch rực rỡ `✈️`, `📍`, `☀️`, `🏝️` với tông màu Sunset Coral.
  * *Study Certificate*: Ngôi sao thành tựu, mũ cử nhân `🎓`, `★`, `🛡️` với tông màu Azure Sapphire.
* **App Loader Transition**: Khi bấm mở app, màn hình phủ mờ sương (Frosted Glass Blur) xuất hiện kèm vòng xoay accent ring và lời nhắn dễ thương.
* **Floating Widget**: Nút capsule góc phải bung mở mượt mà thành hộp thoại góp ý & giới thiệu tác giả.
